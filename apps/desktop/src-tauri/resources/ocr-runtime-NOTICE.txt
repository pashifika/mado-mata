Installation and license retention
  The app streams the archive into its owned staging directory over HTTPS,
  verifies its exact size and SHA-256, and copies only the three reviewed regular
  members to flat, catalog-controlled filenames. LICENSE and
  ThirdPartyNotices.txt are retained unchanged beside the runtime and receipt.
  No license notice is shortened or replaced by this review note.
  Directory rename publishes all four files together. A completed installation
  is reused only after the receipt and every selected file are verified again.
  Existing publications are never repaired in place or silently replaced.
  Runtime and model stages/publications are independent and share the existing
  exclusive setup lease. Recovery only removes known regular staging entries;
  unknown entries and links remain with a distinct cleanup error.

Archive safety
  At most 256 entries, 512 MiB expanded data, and 1 MiB ZIP directory metadata.
  Reject unsafe paths, case-insensitive duplicate destinations, file/directory
  collisions, selected links, hardlinks, special entries and unsupported format
  features. The one reviewed macOS unselected symlink is the only link exception;
  it has no filesystem destination. ZIP duplicate names are rejected before the
  archive library can collapse them. No unpack/extract-all operation, archive
  permissions, shell, package manager, global installation, PATH search, loader
  mutation, binary execution, OCR or engine initialization is used.
